# #1232 read-tool peak-memory parser slice — 2026-11-08

## Scope and behavior

This partial slice replaces the two `std::stoull` calls in the sparse-file read test. A test-local stream seam parses `/proc/self/status` with `std::from_chars`, requires a positive complete `VmHWM` value with the `kB` unit, checks conversion to bytes for overflow, and rejects missing, malformed, duplicated, or unreadable data. Both measurements must succeed, and the second must not be less than the first; a missing reading can no longer turn the 64 MiB memory bound into a false pass. The 256 MiB sparse file, tool execution, bound and measurement order remain in place. This tests the measurement helper; it does not define the read tool's public behavior for status data.
